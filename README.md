# ป๊อกเด้ง Online (Pok Deng Multiplayer)

เกมไพ่ป๊อกเด้งแบบผู้เล่นหลายคน เล่นผ่านเว็บเบราว์เซอร์ ทั้งในวง LAN เดียวกันหรือข้ามเครือข่ายผ่าน tunnel
มีเจ้ามือ 1 คน + ลูกมือ 2-7 คนต่อห้อง (รวม 3-8 คน) เล่นได้ทั้งมือถือและคอมพิวเตอร์ มีระบบเดิมพัน/เงินคงเหลือต่อห้อง

## โครงสร้างโปรเจกต์

```
pokdeng-game/
├── server/
│   ├── main.py              # entry point รัน server

│   ├── network/
│   │   ├── ws_server.py     # WebSocket server
│   │   └── protocol.py      # นิยาม message type
│   └── game/
│       ├── card.py          # Card, Deck
│       ├── player.py        # Player
│       ├── rules.py         # คำนวณแต้ม / เช็คป๊อก / ตัดสินผล
│       ├── room.py          # จัดการห้องเกม (รองรับหลายห้อง)
│       └── game_state.py    # state machine ของห้อง
├── client/
│   ├── index.html
│   ├── css/style.css
```

## วิธีติดตั้ง

ต้องมี Python 3.10 หรือใหม่กว่า

```bash
pip install -r requirements.txt
```

(บน Windows ถ้าใช้ `py` launcher ให้เปลี่ยนเป็น `py -m pip install -r requirements.txt`)

## วิธีรัน server

รันจาก **root ของโปรเจกต์** (โฟลเดอร์ที่มีไฟล์นี้อยู่) ไม่ใช่จากในโฟลเดอร์ `server/`:

```bash
python -m server.main
```

(บน Windows: `py -m server.main`)

Server จะเปิดสองอย่างพร้อมกัน:
- **HTTP server** (default port 8000) — serve หน้าเว็บใน `client/`
- **WebSocket server** (default port 8765) — สื่อสารเกม real-time

เมื่อรันสำเร็จ จะเห็นข้อความบอก URL สำหรับเปิดเล่นในเครื่องนี้ และ URL สำหรับให้เพื่อนต่อผ่าน LAN

## เล่นในวงเดียวกัน (local IP)

ใช้วิธีนี้เมื่อทุกคนอยู่ **Wi-Fi/เครือข่ายเดียวกัน** (บ้าน, ที่ทำงาน, งานปาร์ตี้) ไม่ต้องตั้งค่าอะไรเพิ่ม

1. เครื่องที่รัน server กับมือถือ/คอมของเพื่อน ต้องต่อ **Wi-Fi เดียวกัน**
2. หา IP ของเครื่องที่รัน server:
   - **Windows**: เปิด Command Prompt พิมพ์ `ipconfig` ดูที่ "IPv4 Address" (เช่น `192.168.1.23`)
   - **Mac/Linux**: พิมพ์ `ifconfig` หรือ `ip addr` ดู interface ที่ต่อ Wi-Fi
   - หรือดูจากข้อความที่ server print ตอนเริ่มรัน (บอก IP ให้อัตโนมัติ)
3. บนมือถือ/คอมของเพื่อน เปิดเบราว์เซอร์ไปที่ `http://<IP-ของเครื่อง-server>:8000`
   เช่น `http://192.168.1.23:8000`
4. ในหน้า lobby ปล่อยช่อง "ที่อยู่ server" ว่างไว้ได้เลย (ระบบใช้ host เดียวกับที่เปิดหน้าเว็บอัตโนมัติ)
5. ใส่ชื่อผู้เล่น + ชื่อห้อง แล้วกด "เข้าร่วมห้อง" (คนที่กด "สร้างห้องใหม่" คนแรกจะเป็นเจ้ามือ)

> หมายเหตุ: ถ้าต่อไม่ได้ ให้เช็คว่า firewall ของเครื่องที่รัน server ไม่ได้ block port 8000/8765

## เล่นข้ามที่ (tunnel URL)

ใช้วิธีนี้เมื่อผู้เล่นบางคน **ไม่ได้อยู่ในวงเครือข่ายเดียวกัน** (คนละบ้าน, คนละที่) โดยไม่ต้องแก้โค้ดหรือตั้งค่า router
(port forwarding) เลย — ใช้บริการ tunnel ฟรีสร้าง URL สาธารณะชั่วคราวชี้มาที่เครื่องเรา

วิธีที่ง่ายที่สุดคือ **Cloudflare Tunnel** (หรือจะใช้ **ngrok** ก็ได้เหมือนกัน) แต่ต้องรู้ก่อนว่า tunnel ฟรีของทั้งสองเจ้า
เปิดให้ **1 tunnel ต่อ 1 พอร์ตเท่านั้น** ส่วน server ของเกมนี้ใช้ 2 พอร์ต (HTTP 8000 + WebSocket 8765) จึงต้อง
**เปิด 2 tunnel แยกกัน** — ไม่ต้องแก้ server เลย แค่รันคำสั่งสองครั้ง

### ใช้ Cloudflare Tunnel (แนะนำ — ไม่ต้องสมัครสมาชิก)

ติดตั้ง `cloudflared` ก่อน ([วิธีติดตั้ง](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/))
แล้วเปิด **เทอร์มินัล 2 หน้าต่างแยกกัน** (ต้องรัน server ของเกม `py -m server.main` ไว้ก่อนแล้ว):

```bash
# หน้าต่างที่ 1 — tunnel สำหรับหน้าเว็บ (พอร์ต 8000)
cloudflared tunnel --url http://localhost:8000

# หน้าต่างที่ 2 — tunnel สำหรับ WebSocket (พอร์ต 8765)
cloudflared tunnel --url http://localhost:8765
```

แต่ละคำสั่งจะพิมพ์ URL แบบ `https://xxxx-xxxx.trycloudflare.com` ออกมาคนละอัน (จำไว้ว่าอันไหนคือพอร์ตไหน)

### หรือใช้ ngrok

```bash
ngrok http 8000    # อีก terminal แยกต่างหาก: ngrok http 8765
```

### วิธีใช้ URL ทั้งสอง

1. เอา URL ของ **พอร์ต 8000** ให้เพื่อนเปิดในเบราว์เซอร์ตามปกติ (เหมือนเปิดเว็บทั่วไป)
2. เอา URL ของ **พอร์ต 8765** ไปวางในช่อง **"ที่อยู่ server"** ในหน้า lobby (ไม่ต้องแก้ scheme เอง
   ระบบแปลง `https://` เป็น `wss://` ให้อัตโนมัติ)
3. ใส่ชื่อผู้เล่น + ชื่อห้อง แล้วเข้าร่วม/สร้างห้องได้ตามปกติ

> หมายเหตุ: URL จาก tunnel ฟรีเป็นแบบชั่วคราว เปลี่ยนทุกครั้งที่รันคำสั่งใหม่ และจะหายไปถ้าปิดเทอร์มินัล
> การ deploy ค้างถาวรบน cloud (ให้มี URL คงที่ตลอดไป) เป็นแนวคิดสำหรับพัฒนาในอนาคต ยังไม่ได้ทำในตอนนี้

## วิธีเล่น

1. เจ้ามือกด "สร้างห้องใหม่" — เลือกเงินเริ่มต้นของห้อง (preset หรือกำหนดเอง) ทุกคนที่ join จะได้เงินเริ่มต้นเท่ากันนี้
   คนอื่นกด "เข้าร่วมห้อง" ด้วยชื่อห้องเดียวกัน (รองรับ 3-8 คนต่อห้อง)
2. เจ้ามือกด "เริ่มรอบใหม่" — เข้าเฟส **วางเดิมพัน**: ผู้เล่นที่ไม่ใช่เจ้ามือเลือกจำนวนเงินเดิมพัน (preset หรือกำหนดเอง)
3. เมื่อทุกคนวางเดิมพันครบ ระบบแจกไพ่ 2 ใบให้ทุกคนอัตโนมัติ และเช็คป๊อกทันที (ไพ่ 2 ใบแรกของตัวเองต้องกดค้างเพื่อ "แง้ม" ดู)
4. ผู้เล่นที่ไม่ป๊อก เลือกได้ว่าจะ "จั่วเพิ่ม" (ไพ่ใบที่ 3) หรือ "อยู่"
5. เมื่อทุกคนตัดสินใจแล้ว ระบบเปิดไพ่ทุกคนพร้อมกัน เทียบแต้มกับเจ้ามือทีละคู่ ปรับเงินคงเหลือตามผลแพ้ชนะทันที
6. ถ้าเงินคงเหลือหมด (≤0) จะได้สถานะ "เงินหมด" และไม่ต้องเดิมพันในรอบต่อไป (แต่ยังอยู่ในห้องดูเกมได้)
7. เจ้ามือกด "เริ่มรอบใหม่" เพื่อเล่นต่อได้เรื่อยๆ

## การนับแต้ม (สรุป)

- A = 1 แต้ม, เลข 2-9 = ตามหน้าไพ่, 10/J/Q/K = 0 แต้ม
- แต้มรวม = ผลรวมแต้มไพ่ mod 10 (เอาแค่หลักหน่วย)
- ป๊อก: ไพ่ 2 ใบแรกรวมได้ 8 หรือ 9 = ป๊อก ชนะทันที (ป๊อก 9 ชนะป๊อก 8)
- แต้มเท่ากันระหว่างเจ้ามือกับลูกมือ ถือว่าเจ้ามือชนะ (ตามธรรมเนียมเกมไพ่ไทย)

## แนวทางสำหรับพัฒนาต่อ (ยังไม่ได้ implement)

โครงสร้างโค้ดถูกออกแบบให้เพิ่มฟีเจอร์เหล่านี้ได้โดยไม่ต้องรื้อของเดิม (ระบบเดิมพัน/โต๊ะกลม/ซ่อนไพ่/แง้มไพ่/เล่นข้ามเครือข่าย ทำเสร็จแล้วในโค้ดปัจจุบัน — ไม่อยู่ในลิสต์นี้อีกต่อไป):

- **เด้ง**: ไพ่ 2 ใบแรกดอกเดียวกันหรือคู่ → ได้ 2 เท่า (แก้ที่ `rules.get_hand_result()` ปรับค่า `multiplier`)
- **ไพ่พิเศษ 3 ใบ**: ตอง / สเตรทฟลัช / เรียง / เซียน — เพิ่มฟังก์ชันเช็คใน `rules.py` แล้วเรียกใน `get_hand_result()`
- **หมุนเวียนเจ้ามือ**: เพิ่ม method ใน `Room` ให้เปลี่ยน `is_dealer` ไปคนถัดไปหลังจบรอบ (รวมถึงกรณีเจ้ามือเงินหมด)
- **Reconnect**: `ws_server.py` มี hook ที่ `handle_disconnect()` ไว้แล้ว ขยายเป็นเก็บ session ชั่วคราวรอ reconnect ได้
- **สถิติผู้เล่น**: เพิ่ม field ผลแพ้ชนะสะสมใน `Player` หรือเก็บแยกเป็น dict ใน `Room`
- **Deploy ค้างถาวรบน cloud**: ให้มี URL คงที่ตลอดไปแทนการรัน tunnel ทุกครั้ง (ดูหัวข้อ "เล่นข้ามที่" ด้านบน)
